## tentang

Security researcher — fokus pada analisis malware, reverse engineering, dan detection engineering. Saya bekerja di spektrum ofensif dan defensif, bukan untuk mengeksploitasi, tapi untuk membangun pertahanan yang berangkat dari pemahaman bagaimana serangan benar-benar bekerja.

Saat ini sedang membangun detection tooling, menganalisis sampel PE, dan meneliti pendekatan praktis untuk klasifikasi malware.
