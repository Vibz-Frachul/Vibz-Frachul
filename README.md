### About

Security researcher with a focus on understanding malware behavior, binary structure, and detection logic. I work across both offensive and defensive domains — not to exploit, but to build better defenses from a grounded understanding of how attacks actually work.

Currently building detection tooling, running analysis on PE samples, and researching practical approaches to malware classification.

---

### Research Interests

| Domain | Focus |
|---|---|
| Malware Analysis | Static & dynamic analysis, behavioral profiling |
| Reverse Engineering | Disassembly, decompilation, anti-analysis techniques |
| Detection Engineering | YARA/Sigma rules, detection logic development |
| Threat Hunting | Hypothesis-driven hunting, telemetry correlation |
| PE Analysis | Headers, sections, import anomalies, packer fingerprinting |
| Windows Internals | Syscalls, NTAPI, process and memory mechanics |
| Web Security | Injection vectors, logic flaws, recon automation |
| Vulnerability Research | Root cause analysis, controlled PoC development |
| Recon & Enumeration | OSINT workflows, passive/active surface mapping |

### Current Work

- **Binary analysis projects** — Dissecting samples for behavior, structure, and indicators
- **Malware detection research** — Exploring signature-based and ML approaches to classification
