## ── About ──

Security researcher focused on understanding malware behavior, binary structure, and detection logic. I operate across both offensive and defensive domains — not to exploit, but to build better defenses grounded in how attacks actually work.

Currently building detection tooling, analyzing PE samples, and researching practical approaches to malware classification.

```yaml
alias: vibz
focus: malware_analysis, reverse_engineering, detection_engineering
method: research_driven, opsec_aware
ethics: responsible_disclosure, defensive_only
```

<br />

| Domain | Focus | Tools |
|--------|-------|-------|
| **Malware Analysis** | Static & dynamic analysis, behavioral profiling | IDA Pro, x64dbg, Ghidra |
| **Reverse Engineering** | Disassembly, decompilation, anti-analysis | Ghidra, IDA, dnSpy |
| **Detection Engineering** | YARA/Sigma rules, detection logic | YARA, Sigma, Pluto |
| **Threat Hunting** | Hypothesis-driven hunting, telemetry | KQL, EDR, ELK |
| **PE Analysis** | Headers, sections, imports, packers | pefile, PE-bear, Detect It Easy |
| **Windows Internals** | Syscalls, NTAPI, process/memory mechanics | WinDbg, API Monitor |
| **Web Security** | Injection vectors, logic flaws, recon | Burp Suite, nuclei, httpx |
| **Vulnerability Research** | Root cause analysis, controlled PoC | Custom tooling |

</details>
